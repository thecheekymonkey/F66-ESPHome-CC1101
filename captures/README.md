# Signal Captures

Raw Flipper Zero sub-GHz captures (`.sub`) for this project are located in the [`subghz/`](../subghz) directory:

- **`subghz/ALL BUTTONS SEQUENTIALLY.sub`**: Master RAW recording of all 15 remote buttons.
- **`subghz/SPEED 1 BUTTON.sub`**: Single button RAW capture for Speed 1.
- **`subghz/SEQUENCE README.txt`**: Button press sequence index.
