# Project Images

This directory contains photographic documentation and technical diagrams for the F66 Ceiling Fan Controller project:

- **`REMOTE.jpg`**: Physical F66 / VonLuce 433 MHz remote control handset.
- **`ESP32 PROTOTYPE.jpg`**: Hardware setup showing the ESP32-S3 DevKitC-1 wired to the CC1101 module with an external antenna.
- **`FLIPPER SPECTRUM ANALYSER.jpg`**: Flipper Zero spectrum analyzer displaying carrier frequency measurement (`433.92 MHz AM650`).
- **`HOMEASSISTANT.png`**: Home Assistant dashboard entity card showing all 15 operational controls.
- **`C1101 PINOUT.png`**: Pin assignment reference diagram and wiring schematic for the CC1101 wireless module.
